# Histórico de versões

## v2.0.0 — Base de Produção

- Frontend conectado a uma API central.
- FastAPI e PostgreSQL.
- Autenticação por token com expiração.
- Senhas derivadas com PBKDF2-HMAC-SHA256 e salt individual.
- Usuários e perfis de acesso.
- Pessoas, protocolos, depósitos e movimentações.
- Regra de bloqueio de saldo negativo no servidor.
- Cancelamento lógico de movimentações.
- Livro de Controle, Termo de Abertura e Termo de Encerramento.
- Biblioteca normativa e histórico de alterações.
- Checklist, pendências, produtividade e auditoria.
- Backup e restauração de dados operacionais.
- Migrações Alembic.
- Infraestrutura declarativa para Render.
- Configuração de frontend estático para Vercel.

## v1.2.0 — Escopo Integrado

- Demonstração estática com todos os módulos planejados.
- Armazenamento local no navegador.
